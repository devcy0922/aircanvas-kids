# Handoff — 2026-08-25 핵심 블로커 해결 및 배포 준비 완료 (v0.2 최종)

## 1. 완료된 핵심 작업

1. **[TASK-015] `fill-at` 좌표 기반 채색 프로토콜 추가**:
   - `packages/protocol`: `TVCommand`에 `{ type: 'fill-at', x: number, y: number, color: string }` 추가.
   - `apps/tv`: `TVCommandHandler.handleFillAt` → `GameEngine.onFill(x, y, color)`로 TV 화면 내 SVG Region Path2D `isPointInPath` 히트테스트 및 채색 연동.
   - `apps/phone`: `GameStateMachine.onFillAt` 추가.
2. **[TASK-016] 서버 `GET /announce` 디스커버리 엔드포인트 및 CORS 허용**:
   - `server`: `GET /announce` 핸들러 추가 (TV 룸 탐색 및 announcement JSON 반환).
   - `tower-http` CORS permissive 레이어 적용하여 브라우저에서 `/announce` fetch 시 CORS 차단 해결.
3. **[TASK-010] Pinch 제스처 실연동 마무리**:
   - `apps/phone/src/App.tsx`:
     - 손 추적 루프에서 `hand.pinch` 감지.
     - 채색 모드(`fill`): 핀치 시작 순간(`isPinching && !wasPinching`)에 `onFillAt(clamped.x, clamped.y, color)` 호출 및 모바일 햅틱 진동 피드백 (`navigator.vibrate(40)`).
     - 드로잉 모드(`free`): 핀치 유지 중 스트로크 좌표 수집, 핀치 해제 시 `onStrokePoints` 일괄 전송.
4. **[TASK-009] & 도메인 독립성 (play.aircanvas.kr 등 임의 도메인 배포 준비)**:
   - `SERVER_BASE` / `CONTENT_SERVER_BASE`: URL 쿼리 파라미터가 없으면 `location.protocol` (https 여부) 및 `location.host`를 기반으로 동적 탐지 (`wss://play.aircanvas.kr` 등).
   - `wsUrl`: `http://` → `ws://`, `https://` → `wss://` 자동 변환.
   - `base: './'` 설정: Nginx 서브패스나 정적 디렉토리 마운트 시 에셋 경로 깨짐 방지.
   - 로컬 테스트용 `@vitejs/plugin-basic-ssl` 및 `npm run dev:ssl` 지원.
