## 1. 완료된 작업 요약

1. **AI 코딩 툴 배포 체계 (Govail 방식 반영)**:
   - **루트 AI 진입점 가이드 구축**:
     - `AGENTS.md` (통합 AI 에이전트 부팅 가이드)
     - `CLAUDE.md` (Claude Code 전용 가이드)
     - `ANTIGRAVITY.md` (Antigravity 전용 가이드)
     - `CODEX.md` (Codex / ChatGPT용 가이드)
     - `GEMINI.md` (Gemini CLI용 가이드)
   - **도구 심볼릭 링크 자동화 (`agents/scripts/link-tooling.sh`)**:
     - `.agents -> agents/`
     - `.cursor/rules/aircanvas-core.mdc -> agents/rules.md`
     - `.cursor/rules/frontend-design.mdc -> agents/skills/frontend-design/SKILL.md`
     - `.github/copilot-instructions.md -> agents/rules.md`
2. **모노레포 표준 `Makefile` 구축**:
   - `make build`: 전체 TS 번들링 + Rust 릴레이 서버 릴리즈 빌드.
   - `make check`: `npm run build` + `cargo check` 검증 게이트.
   - `make agents-link`: AI 코딩툴 심볼릭 링크 자동 배포.
   - `make dev-phone` / `make dev-phone-ssl`: 폰 개발 서버(HTTP / HTTPS).
   - `make dev-tv`: TV 개발 서버.
   - `make dev-server`: Rust 릴레이 서버 실행.
3. **`agents/skills` 최신 작업 반영 및 UI 스킬 동기화**:
   - `frontend-design`: Claude Code 표준 UI 디자인 스킬 (SSOT).
   - `aircanvas-protocol`: `fill-at`, `GET /announce`, `wsUrl` 도메인 자동 변환(http->ws, https->wss).
   - `aircanvas-calibration-tracking`: 손 추적 및 Pinch 제스처(채색 트리거 및 드로잉 궤적), 햅틱 피드백.
   - `aircanvas-tv-engine`: `Path2D.isPointInPath` 기반 `fill-at` 히트테스트 및 채색.
   - `aircanvas-relay-server`: `GET /announce` 디스커버리 및 CORS 허용.
