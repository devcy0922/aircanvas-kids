# kids 디자인 가이드

> UI 작업은 먼저 `frontend-design` 스킬로 계획을 세우고, 이 스킬의 콘셉트·토큰을 따른다. 토큰 원본: `packages/ui/tokens.css`.

## 콘셉트: 숲 속의 아침

깊은 숲 녹색 바탕에 따뜻한 살구색 포인트와 크림색 글자. 가는 원(orb) 윤곽이 배경에서 해·달무리처럼 떠 있다. 글자는 두껍고 자간을 조인다(제목 `letter-spacing -0.06em` 안팎).

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--kids-forest-950` / `-800` / `-700` | `#12231d` / `#244a3b` / `#2f5d4a` | 바탕, 진한 카드, 보호자용 강조 |
| `--kids-cream` | `#fffdf7` | 글자, 밝은 카드 |
| `--kids-peach` / `-soft` | `#ef9b58` / `#f4b37a` | 주요 버튼(글자는 `--kids-ink`), 포인트 |
| `--kids-peach-deep` | `#b4571a` | 흰 바탕 위 살구색 **글자**(대비 4.5:1) |
| `--kids-sage` | `#b5d99c` | 진한 바탕 위 보조 글자 |
| `--kids-ink` | `#15231d` | 밝은 바탕 글자 |

## 화면 원칙

- **대상으로 톤을 가른다**: 아이용 = 숲 녹색(진한) 카드, 보호자용(엄빠) = 크림(밝은) 카드. 정보 밀도가 높은 화면(엄빠 목록)은 밝은 바탕을 쓰되 상단 바·버튼·선택 색으로 콘셉트를 잇는다.
- 장식 일러스트는 **이모지**를 쓴다. 공룡 5종 일러스트는 이용 허락 확인 전(`provenance` "미상")이라 게임 밖(포털 등)에 쓰지 않는다.
- 카피는 사용자 눈높이로, 문장형 한국어, 버튼은 동사로 끝낸다(`놀러 가기`, `일정 보기`). 시스템 용어를 쓰지 않는다.
- 데모·미확인 데이터는 화면에서 정직하게 밝힌다(배지·안내문).
- 모션은 진입 시 한 번(카드 이모지)만. 사용자 동작에 답하는 것(탭 눌림)은 허용. `prefers-reduced-motion`을 지킨다.
- 품질 바닥: 360px 폭에서 가로 스크롤 없음, 키보드 포커스 링(`--kids-peach`), 터치 대상 44px 안팎, 글자 대비.

## 새 화면을 만들 때

1. `import '@ht/ui/tokens.css'`(Vite 앱) 또는 `kids-tokens.css` 복사본(정적 앱, `tools/sync-ui.mjs`)을 쓴다. 색을 직접 쓰지 말고 토큰 변수를 쓴다.
2. 새 `className`에는 같은 변경에서 CSS를 추가한다(rules §5 — 마크업만 바꿔 화면이 깨진 전례).
3. 폰 크기 스크린샷(390×844, 360×640)과 넓은 화면(1280)을 직접 보고, `make site-smoke`/`make ui-smoke`를 통과시킨다.
