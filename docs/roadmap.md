# 로드맵

## M1 — MVP (현재 세션 산출물)
- [x] Rust 릴레이 서버(방 코드 세션, 좌표 릴레이)
- [x] 폰: MediaPipe 손 추적 + 4점 호모그래피 캘리브레이션 + One-Euro 필터
- [x] TV: 커서/그리기/8색 팔레트/실행취소
- [x] 색칠: region 채색 + 진행도 판정 + 완성 이펙트 + 테마 월드 갤러리
- [x] 콘텐츠 30종(공룡/정글/바다 × 10)

## M2 — 플레이 경험 고도화
- [ ] 핀치(pinch)로 브러시 on/off 완전 지원 + 손바닥 포즈로 지우개
- [ ] 미션 모드: "물고기를 그려보세요" 가이드 윤곽 + 따라그리기 점수
- [ ] 효과음/BGM(테마별), 완성 축하 사운드
- [ ] TV 리모컨 풀 네비게이션 + 터치 폴백 강화

## M3 — 인식·지능
- [ ] 그림 모양 인식(코르크스크류 서명/푸리에 기술자 or 경량 CNN)으로 "무엇을 그렸는지" 판정
- [ ] llm-gateway(vLLM)/MLX 폴백 정책에 따른 그림 해설·칭찬 문구 생성(오프라인 우선)
- [ ] 아이 실력에 따른 난이도 자동 조절(region 수/복잡도)

## M4 — 멀티·확장
- [ ] 폰 다대 접속(가족 동시 색칠, 최대 4명)
- [ ] 펜/크레용 물체 추적(색상 캡 끝 검출) — MVP는 검지 우선
- [ ] 작품 저장소(NAS `/storage/nas` 연동 옵션), QR로 작품 내려받기
- [ ] PWA 오프라인 캐시, TV 앱 패키징(Tizen/webOS 래퍼 검토)

## 기술 부채/리스크
- TV 브라우저별 WASM/SIMD 지원 차이 → MediaPipe legacy 솔루션 폴백 검토
- 카메라 자동 노출 변동에 따른 마커 인식 안정성 → 수동 모드 유지 보강
- 저사양 스마트 TV PixiJS 성능 → 파티클 수 상한/해상도 스케일 옵션
