# 콘텐츠 파이프라인 — 30종 아트워크 (v0.1)

## 1. 데이터 모델

```ts
interface Region { path: string; label: string }
interface Artwork {
  id: string;            // 예: "dino-trex"
  theme: 'dino'|'jungle'|'ocean';
  name: string;          // 한국어 표시명
  viewBox: string;       // SVG 좌표계 (0 0 100 100 통일)
  regions: Region[];     // 색칠 가능 영역 (외곽→내부 순서)
}
```

- 모든 아트워크는 `viewBox="0 0 100 100"` 으로 통일하여 hit-test/스케일을 단순화한다.
- `regions[0]`은 바디 등 큰 영역, 이후 세부 영역 순. 겹침은 SVG 페인트 순서로 해결.
- region path 는 닫힌 형태(`Z` 종료)여야 hit-test(`isPointInFill`)가 동작한다.

## 3. 색칠 진행도 판정 알고리즘

TV 클라이언트는 각 region 별로:

1. region 을 자체 `<canvas>`(256×256 offscreen)에 흑백으로 렌더 → 면적 픽셀 수 `A`.
2. 사용자가 `fill(x,y,color)` 요청 → SVG hit-test로 대상 region 특정.
3. 채색 레이어 canvas 에 해당 region 을 clip 후 브러시 스탬프 누적.
4. 채색 레이어에서 region bbox 스캔 → 채워진 픽셀 수 `p` / `A` = 진행도.
5. 전체 진행도 = Σ(p)/Σ(A). 85% 이상이면 "완성" 판정(MVP 기준).

완성 판정 시:
- 파티클 버스트(PixiJS) + 스케일 펄스 연출
- 1.6초 후 해당 테마 월드 씬으로 전환, 아트워크가 제자리에 부유하며 등장
- 갤러리에는 작품 썸네일(채색 레이어 snapshot)이 누적됨

## 4. 아트워크 추가 방법

1. `packages/tv-art/src/artworks/<theme>.ts` 에 `Artwork` 객체 추가.
2. `regions` 의 path 는 반드시 닫힌 경로로 작성하고, viewBox 100×100 안에 배치.
3. `docs/content-pipeline.md` 표 갱신.
4. TV 앱에서 해당 테마 선택 시 자동 노출 확인.
