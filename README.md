# S-Kids — 서울형 키즈카페 통합 검색

> 가까운 서울형 키즈카페를 찾고, 아이가 이용 가능한 시설의 예약 현황을 한눈에 비교한 뒤 공식 예약 페이지로 이동하는 서비스.

**상태: 기획 / 데이터 수집 PoC 이전 (2026-10-14 기준)**  
서울시 공식 운영 서비스가 아니며, 서울시와 제휴하거나 운영을 위탁받은 서비스가 아닙니다.

## 문제 정의

서울형 키즈카페 시설·이용 연령·예약 회차가 여러 페이지에 분산되어 있어, 부모가 **우리 아이가 갈 수 있고, 가까우면서, 원하는 날짜에 자리가 있는 시설**을 비교하기 번거롭습니다.

S-Kids는 예약을 대신하지 않습니다. 시설 조건과 **마지막 확인 시각이 표시된** 예약 현황을 비교하고, 예약·로그인·결제는 공식 포털에서 진행하게 합니다.

## MVP 핵심 기능

- **자치구 필터**: 한 개 또는 여러 자치구 선택
- **내 위치 반경 필터**: 1 / 3 / 5 / 10km (위치 허용 시, 거리는 직선거리 기준)
- **이용 연령 필터**: 아이의 나이로 시설 이용 가능 여부 판단. 시설별 개월 수·연나이·보호자 동반 조건은 원문 기준으로 검증
- **날짜 선택 및 회차별 현황**: 오늘/이번 주말 등을 빠르게 선택, 회차별 확인된 잔여 인원/마감/미오픈/휴관/미확인 표시
- **수동 새로고침**: 사용자가 선택한 시설에 한해 새 조회 요청. 서버 단위 중복 요청 방지 및 호출 간격 제한 적용
- **공식 예약으로 이동**: 지점별 공식 예약 URL로 이동

## 갱신 정책 (제안, 운영 허가 전 미적용)

- 기본 캐시 유효시간(**TTL**) **5분**. '실시간'을 보장하거나 광고하지 않음
- 데이터마다 \`last_checked_at\` 및 상태 표시; 오래된 숫자는 최신인 것처럼 표시하지 않음
- 사용자가 **새로고침**을 누르면 특정 지점/날짜만 재조회 시도
- 같은 지점에 대한 동시 새로고침은 하나의 작업으로 합침(singleflight)
- 서버 측 최소 요청 간격(초기 제안 60~90초), 사용자별 요청 제한, 전체 호출량 상한
- 호출 허용·한도 검증 전에는 반복 크롤러 운영 금지. 403/429/CAPTCHA 발견 시 중단 또는 제한
- 새 조회 불가능하면 최신 확인된 캐시 및 '현재 확인 불가' 상태 제공
- 실제 갱신 주기와 한도는 **운영기관 허용 범위 확인 후 확정**

## 데이터 출처와 확인 상태

| 항목 | 출처 | 검증 상태 |
| --- | --- | --- |
| 시설명, 위치, 운영일, 정원 등 | [서울 열린데이터광장 시설현황정보](https://data.seoul.go.kr/dataList/OA-21716/S/1/datasetView.do) | 공식 공개 데이터셋 확인 |
| 회차별 달력 표기 | [우리동네키움포털 예약 페이지 예시](https://umppa.seoul.go.kr/icare/user/kidsCafeResve/BD_selectKidsCafeResveCal.do?q_fcltyId=SC240801) | 공개 페이지에 숫자 표시 확인 |
| \`q_fcltyId\`를 통한 지점별 경로 | 같은 공식 예약 페이지 | 일부 샘플 URL 확인, 전체 시설 매핑 미완료 |
| 비로그인 자동 HTTP 수집 | 공식 예약 페이지 | **미검증** (브라우저/검색 인덱스에서 열람되는 것과 별개) |
| 로봇 정책/WAF/호출 제한 | 공식 예약 사이트 | **미검증** |
| 예약 데이터의 상업적 재표시·주기 수집 허용 | 운영기관 확인 필요 | **미확인, 법적 검토 필요** |

**중요:** 시설현황 데이터셋의 공공누리 제1유형(출처표시, 상업적 이용 및 변경 가능)은 **그 데이터셋**에 관한 조건입니다. 별도 예약 달력 데이터에 자동 적용하지 않습니다. 예약 수집과 재배포 허용을 확인하기 전에는 이를 당연히 적법한 수집으로 간주하지 않습니다.

## 사용자 흐름

1. 접속 → 위치 사용 동의(선택) 또는 자치구 지정
2. 아이 나이 + 반경 선택 → 날짜 선택(기본 오늘 또는 가장 가까운 주말)
3. 시설 리스트에서 거리, 대상 연령, 회차별 예약 현황, 마지막 확인 시간 확인
4. 필요 시 '새로고침' → 서버의 안전한 캐시 갱신
5. '공식 예약' → 서울시 예약 페이지에서 실제 예약 진행

예약 가능 숫자는 변동될 수 있으며 **예약 확정·보유·보장**을 의미하지 않습니다.

## 기술 설계 방향 (아직 미구현)

\`\`\`text
서울시 공개 시설정보 ──> 시설 Registry / 정규화 / 좌표화
                                  │
공식 예약 페이지 ──> (허가·검증 이후) Collector ──> 5분 캐시
                                  │                │
                                  └── 검색 API <───┘
                                        │
                               필터 UI + 상태 표시
                                        │
                                  공식 예약 이동
\`\`\`

- \`facility_id\`와 검증된 \`reservation_url\`을 Registry에 저장하고, 매번 목록 페이지를 탐색하지 않음
- 위치 필터는 PostgreSQL/PostGIS 등을 후보로 검토하며, 초기 MVP는 단순 거리 계산으로도 가능
- 회원가입·예약 대행·계정 정보 저장은 범위에서 제외
- 수집 허가가 나지 않으면 시설/연령/위치 검색 + 공식 예약 링크 중심으로 제공하고 잔여석은 '확인 불가'로 표시

## 면책 및 운영 원칙

모든 예약·대기·취소·이용 조건의 최종 기준은 [서울시 공식 포털](https://umppa.seoul.go.kr/)입니다. 자동 수집은 사이트 운영 정책과 권리를 준수하며, 인증·CAPTCHA·IP 차단을 우회하지 않습니다. 본 저장소의 법적 검토 문서는 확정적인 법률 자문이 아닙니다.
