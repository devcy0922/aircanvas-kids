예약은 공식 포털에서

S-Kids는 시설을 비교하고 다음 행동을 준비하는 서비스입니다. 로그인, 결제, 예약 확정은 서울시 우리동네키움포털에서 진행해 주세요.

지금 데모에서 확인하는 것

  • 날짜·나이·위치에 맞는 시설 탐색
  • 시설별 회차 현황과 마지막 확인 시각
  • 마음에 드는 장소를 브라우저에 저장
  • 실제 데이터 연결 전까지의 화면 흐름

데이터 안내

시설 목록은 서울 열린데이터광장 시설현황정보 스키마를 참고한 예시입니다. 회차 현황은 데모 시뮬레이션이며 실제 잔여석이나 예약 가능을 의미하지 않습니다.
